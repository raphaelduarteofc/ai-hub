# ELEAR Sales Brain — Kommo widget de teste

Pacote isolado para disponibilizar o bloco `salesbot_designer` no Kommo.

Depois do upload, configurar o endpoint mostrado no campo do widget como:

`https://elear-sales-brain-test.netlify.app/widget-request`

Este pacote apenas envia o evento para a fila de teste. Não envia mensagens ao cliente, não altera leads e não habilita o fluxo de produção.
